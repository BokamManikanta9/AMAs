## 1. What is the shortcut key to open the terminal?
In Linux, **Ctrl + Alt + T** is commonly used to open the terminal.

## 2. What is the use of `split()` in Python?
`split()` is used to split a string into smaller parts. By default, it splits using spaces.

## 3. What are primitive data types?
Primitive data types are basic types used to store simple values. Examples are **int, float, string, and boolean**.

## 4. How to list all processes in CLI?
In Linux, we can use:
```bash
ps -ef
```
It shows the processes  on the system.

## 5. What is OOPs in Python?
OOPs means **Object-Oriented Programming**. It organizes a program using **classes and objects**, making code easier to manage and reuse.

## 6. What will happen if we don't use the `label` tag with an input?
The input will still work, but there will be no proper text label connected to it. This can make the form less clear and less accessible.

## 7. What are some Python libraries?
Some common Python libraries are:
- NumPy
- Pandas
- Matplotlib
- Requests

## 8. Why do we use Flexbox?
Flexbox helps us arrange elements easily in a row or column. It is useful for alignment, spacing, and responsive layouts.

## 9. What is DML in SQL?
DML stands for **Data Manipulation Language**. It is used to add, change, or remove data. Examples are `INSERT`, `UPDATE`, and `DELETE`.

## 10. What is the difference between RANK and DENSE_RANK?
`RANK()` gives the same rank to equal values but skips the next rank.  
`DENSE_RANK()` gives the same rank but does not skip any rank.

Example:
```text
Values:       100, 100, 90
RANK:           1,   1,  3
DENSE_RANK:     1,   1,  2
```

## 11. What is a global variable in Python?
A global variable is created outside a function. It can be accessed from different functions in the program.

## 12. What is the default flag used with the `kill` command?
The default signal used by `kill` is **SIGTERM (15)**. It asks the process to terminate normally.
